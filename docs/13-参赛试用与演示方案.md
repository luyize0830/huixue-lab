# v0.27 参赛试用与演示方案

本文件是待执行方案，不是已经完成的用户研究。工程验证见 [v0.27-validation.md](v0.27-validation.md)，当前没有可报告的真实试用接受率或健康改善结论。

## 1. 收紧参赛主张

建议主张：**面向大学生学习间隙，把可解释状态、个人行动池和反馈驱动推荐连成可验证的五分钟行动流程。**

答辩时分别讲清：状态分是经验规则；推荐用端侧 Thompson 采样；大模型是可选对话辅助。手环提供实时心率和可用的 RR 间期，不能把一次心率变化当成医学诊断或因果效果。创新落点是个人可执行候选、时间/场景约束、可恢复体验、反馈和过程记录的结合。

## 2. 先做 10 人访谈

招募经常有长时学习任务的同学，覆盖有/无手环、住校/通勤等情境。先询问经历，再展示产品，避免诱导“你是否喜欢这个功能”。每人约 15–20 分钟，自愿参与，可不回答或退出。

1. 最近一次学习到疲惫是什么时候？当时你怎么发现、怎么处理？
2. 如果只有 3–5 分钟，你通常做什么？哪些事情在教室/图书馆不方便？
3. 目前用过哪些计时、运动或放松工具？哪次没有坚持，为什么？
4. 看到一个状态分，哪些依据会让你相信或质疑它？
5. 用原型完成一次选择和反馈，在哪一步犹豫或误解？
6. 哪些提醒会打扰你？愿意保留或分享哪些记录？

记录表字段：匿名编号、场景、现有做法、原话摘录、观察到的操作困难、改进建议、是否愿意试用。姓名/联系方式单独保存，不提交仓库；引用原话需征得同意。整理问题频次时同时保留人数和分母，不把 10 人意见外推到全体大学生。

## 3. 8–12 人、14 天试用

这是可行性与可用性试用。使用同一 v0.27 包，记录正式/兼容签名、手机系统、有无手环及权限情况。参与者按自己的学习节奏使用，行动可拒绝，不要求为凑次数反复点击。

| 阶段 | 工作与产物 |
|---|---|
| 开始前 | 说明用途、来源、退出与删除方式；本人完成首次操作；单独记下演示期，正式采集前清理练习数据 |
| 第 1–3 天 | 记录无法安装、权限失败、不会操作和提醒打扰；修复若变更版本须注明日期 |
| 第 4–13 天 | 自然使用；记录失败、缺失、跳过原因和主动退出，不补造数据 |
| 第 14 天 | 自愿导出推荐 CSV 与反馈 CSV；做 10 分钟回访，确认是否愿意继续使用 |
| 汇总 | 核对来源、日期范围、会话关联及分母，报告人数、有效天数、缺失与退出 |

没有健康改善证据时，报告“可用性、采纳、主观体验”。不要要求参与者故意熬夜、屏息或运动来制造异常分数。出现不适即停止行动，不把应用代替专业照护。

## 4. 指标与分析口径

| 指标 | 定义与注意事项 |
|---|---|
| 推荐展示 | 首页推荐页一批候选为一轮；重组不重复记数，换批形成新轮 |
| 接受率 | 非 DEMO 已选择轮次 / 非 DEMO 展示轮次 |
| 反馈完成率 | 有关联反馈的非 DEMO 已选择轮次 / 非 DEMO 已选择轮次 |
| 主观有帮助比例 | 指定试用窗口内，评分 ≥4 的有效反馈 / 有效反馈；注明缺失反馈数 |
| 参与情况 | 参与者数、实际使用天数、保留到第 14 天人数；不能从实验条数推算天数 |
| 操作与稳定性 | 安装/授权失败、崩溃、掉线、恢复失败、打扰投诉的次数及对应人数 |

先按人报告分子/分母，再给总体合计，避免少数高频用户掩盖其他人。分母为零写“无可计算样本”。网页全部 DEMO，安卓未获真实行为输入时也可能带演示标志；日志只保留最近 5000 轮，旧版本没有的曝光不能倒推。

当前 F-43 只统计首页推荐流程，从聊天或行动池直接开始不属于该接受率。进程被终止时可能保留未决 SHOWN，不能全部解释为明确拒绝。不要仅凭已选择记录宣称个性化策略优于随机策略；正式比较需先设计分配方式、策略版本和分析计划。

## 5. 90 秒演示脚本

发布附件含带说明字幕的网页演示视频；视频全程是演示数据，提前结束计时用于展示流程。注入心率的 UI 测试另列为工程证据；本轮真实 BLE 有效截图尚未获得。

| 时间 | 画面 | 讲述重点 |
|---|---|---|
| 0–10 秒 | 今天首页 | 学习间隙，五分钟内选择一件可执行的事 |
| 10–22 秒 | 展开分数依据 | 来源和缺失可见，状态分为经验规则 |
| 22–35 秒 | 三个候选 | 个人行动池、时间约束、反馈驱动推荐 |
| 35–45 秒 | 行动计时 | 显示第一步，选择与会话同时保存 |
| 45–60 秒 | 暂停、刷新、恢复 | 中断后仍保留进度；现场说明提前结束演示 |
| 60–72 秒 | 评分反馈 | 自评更新后验，心率仅作辅助观察 |
| 72–90 秒 | 图谱与推荐统计 | 解释分母、演示隔离和 CSV，不展示虚构试用结果 |

现场手机主演示先确认电量、权限、手环广播及联网条件；本地网页和视频作备选。模型对话作为附加展示，核心推荐不依赖模型服务。不要临时卸载已有数据的手机应用来切换签名。
