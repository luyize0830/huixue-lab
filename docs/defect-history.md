# 历史缺陷 BUG-01–BUG-37

保留原编号，来源为 v0.25 测试文档；当前缺陷见 05 文档。


| 编号 | 现象 | 根因 | 处理 |
| --- | --- | --- | --- |
| BUG-01 | 安装报 `INSTALL_FAILED_USER_RESTRICTED` | 未开 USB 安装 | 开启后重装 |
| BUG-02 | `INSTALL_FAILED_TEST_ONLY` | debug 包 test-only | 加 `-t` |
| BUG-03 | 扫描拿不到设备，权限恒 DENIED | `ACCESS_FINE_LOCATION` 带 `maxSdkVersion="30"`，新系统等于未声明 | 改 `BLUETOOTH_SCAN`/`CONNECT` + `neverForLocation` |
| BUG-04 | 对话候选序号从 0 起 | 下标直接当序号 | 从 1 起算 |
| BUG-05 | 按系统返回键直接退出桌面 | 未拦截返回 | 加 `BackHandler` 回首页 |
| BUG-06（设计） | 深夜推社交行动 | 采样未接时段 | 深夜模式（23–5 只推 REST/CALM/FUEL）+「换一批」 |
| BUG-07 | 回血池只能「删」 | 漏了行动入口 | 每行补「开始」直达计时 |
| BUG-08（设计） | 反馈页 emoji 打分与整体视觉不一致 | v0.5 未覆盖反馈页 | 改 5 段文字，选中橄榄绿实心 |
| BUG-09 | 分类胶囊"动 动一动" | 短名与全名重复拼 | 只渲染全名 |
| BUG-10 | 筛选胶囊不滚动，「玩一下」挤三行 | `Row` 换行 | 改 `horizontalScroll` |
| BUG-11（设计） | 空时段画成满格空槽 | 未区分"没有"与"为 0" | 不画槽，给文案 |
| BUG-12 | 点 HC「去授权」弹回首页 | 缺 rationale Activity | 补 Activity + 三态 |
| BUG-13 | 设备全堆在首页 | 无列表与排序 | 扫描页 + 像手环优先 + RSSI |
| BUG-14 | 子页返回一律回首页 | `BackHandler` 只认首页 | 按来源返回 |
| BUG-15（设计） | 图标仍是模板绿机器人 | 沿用模板 icon | 重画「回」+ 麦色点 |
| BUG-16 | 报告页时段标签折行 | 按短标签估宽 | 92dp + `maxLines = 1` |
| BUG-17 | Key 不校验，掉字符照存 | 只判非空 | 要求 `sk-` 开头 ≥20 位 |
| BUG-18（设计） | 每条回复硬塞三个行动按钮 | `actionIds` 强制、空数组判失败 | `parse` 允许空数组、不渲染卡片 |
| BUG-19（设计） | 接入入口藏在第三屏 | 未接入时角色卡整张隐藏 | 未接入也显示，CTA 直达设置 |
| BUG-20 | 通知弹窗盖在认脸页 | `onCreate` 直接申请 | 挪到登录之后 |
| BUG-21（设计） | 旧弹窗与认脸页并存 | 只加新页未删旧的 | 删 76 行死代码，编辑跳同页 |
| BUG-22（设计） | 提示词写成规矩清单，句式重复 | 抽象约束而非示例 | 示例对照 + 五档可编辑 |
| BUG-23 | 点「先不填，随便逛逛」后冷启动仍弹认脸页 | 未记「已看过」 | `ProfileStore` 加 `seen`/`markSeen`（`seen_v1`） |
| BUG-24 | 没接入模型仍写 pending，话永远显示不出来 | 未查 Key | `llmKey.isNotBlank()` 才调（`557345a`） |
| BUG-25 | 任何模型失败都显示「刚才没连上模型」，Key 失效与地址错分不清 | `ask()` 失败统一 return null，未判 `isReady` | `LlmResult` 三态 + 错误码映射 + 提示条 |
| BUG-26 | 「模型回的话我没看懂」其实请求成功；回复里还夹「cold / 冷水洗把脸」 | 非 JSON 被当错误；清单回显未过滤 | 非 JSON 当正文；`dropPoolEcho()` 滤整行 |
| BUG-27 | 200 网页误报连通、旧检测结果残留 | 只看状态码 | 共用响应解析、编辑后清除结果 |
| BUG-28 | 自定义性格只偶尔生效 | 精简请求未带性格 | 每轮发送性格与边界 |
| BUG-29 | 连发重复上下文、出队失败无回复 | 批次边界缺失 | 独立队列、历史快照、逐批兜底 |
| BUG-30 | 网页零预算超时、两端图书馆限制失效 | 假值判断与回退绕过条件 | 明确空值、先应用硬约束 |
| BUG-31 | 网页异常存储导致打不开 | 直接信任 JSON 结构 | 恢复默认值、保留有效记录 |
| BUG-32 | 本机记录可能进入系统备份迁移 | 模板规则未排除 | 关闭备份并排除 SharedPreferences |
| BUG-33 | 纯行动清单仍当回复、冒号丢失 | 过滤后还原、改写普通文本 | 纯清单降级、保留标点 |

| BUG-34 | 计时退出或重建后丢进度 | 只靠界面倒计数 | 会话落盘，回前台按截止时间重算 |
| BUG-35 | 改行动会影响历史标题/类别 | 记录只留行动编号 | 开始时保存行动快照 |
| BUG-36 | 重复反馈或导入可能叠加 | 缺会话标识和整体替换 | 会话号去重，备份整体替换 |
| BUG-37 | 网页评分选中提示错位 | 1 分值与 0 下标混用 | 统一按 1–5 高亮与存储 |
