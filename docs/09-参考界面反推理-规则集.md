# 09 · 参考界面反推理：从六屏截图到一套可复用的界面规则

> 目的：不是"抄一个好看的界面"，而是把参考产品（Hevy，健身记录）的**画面逻辑**反推成规则，再按我们的场景重新实现。
> 结论先行：我们只搬「信息怎么组织、动作怎么放、数字怎么排」，不搬它的黑底荧光绿配色和健身语境。

## 一、被反推的六屏（原始观察）

| # | 屏幕 | 关键画面元素 |

## 二、反推出的 12 条规则

### R1 · 一个 App 只能有一个"主按钮"
六屏里绿色实心块只出现在两种位置：底栏中央的圆按钮，和详情页底部的主 CTA。其余动作全部是文字按钮或描边块。
→ **规则：实心强调色 = 全局唯一主路径。** 我们对应：底栏中央闪电键 + 首页「撑不住了」大按钮（同一件事的两个入口，视觉层级一致）。

### R2 · 底栏固定四格 + 中央主按钮，任何页最多两次点击回到核心动作
标签是名词（今天/计划/统计/动作库），中央是动词（开始）。
→ **规则：名词进底栏，动词进中心。** 我们：今天 / 回血池 / ⚡ / 图谱 / 陪练。

### R3 · 统计页顺序 = 先回答"我这周怎么样"，再回答"哪一天"
2×2 大数字卡在最前，热力格在中间，分项列表在最后。数字比标签大三倍，用户扫一眼就够。
→ **规则：结论（大数字）→ 分布（热力格）→ 明细（列表）。** 我们：实验次数 / 平均有效分 / 觉得有用的比例 / 心率下降次数 → 回血日历 → 时段画像。

### R4 · 大数字卡只放两个指标：一个值 + 一个小标签
没有单位换算、没有对比箭头、没有迷你折线。
→ **规则：一格只回答一个问题。** 我们保留 `StatCard(value, label, hint?)`，hint 只在必要时出现（例如"共 0 次采到心率"）。

### R5 · 空态必须给出口，不能只写"暂无数据"
动作库空态写"创建自己的动作"，计划空态写"加载入门计划"，都带一个可点的文字按钮。
→ **规则：空态 = 一句解释 + 一个动作。** 我们：搜索无结果写"没有完全符合的，把条件放宽一点"，详情页没记录写"这个还没试过。第一次做完，它才会进入你的图谱。"

### R6 · 筛选用胶囊，不用下拉框；胶囊可横向滚动，不换行
部位/类型/器械三排胶囊横排，超出一屏就滑动。换行会把一块区域撑高，留下大片空白。
→ **规则：筛选项一律单行可滚动。** 我们初版用 Row 不滚动，结果「玩一下」被挤成三行、下面空出一大块——v0.6 已改为 `horizontalScroll`。

### R7 · 列表行的信息位固定为三块：图标 / 标题+副标题 / 右侧动作
副标题永远是「属性 · 属性」格式（"心血管系统 · 自重"），右侧永远是同一种绿色文字动作。
→ **规则：行内位置固定，用户第二次看就不用重新找。** 我们：汉字贴纸 / 标题 + 「类别 · N 分钟」/ 右侧箭头（点整行进详情）。

### R8 · 详情页自上而下的顺序不可变：视觉 → 标签 → 做法 → 主 CTA → 参数 → 说明
说明文字永远是灰色的、比正文小一号，专门用来"把话说死"（预测值不是实测）。
→ **规则：先给感官，再给事实，最后给免责口径。** 我们：大贴纸区 → 类别/时长/场景标签 → 一句 cue（"一层一层走，不用快"）→「开始 N 分钟」→「上次之后」历史 → 灰字说明"做完回来点一下有没有用，我按你的反馈决定下次还推不推它"。

### R9 · 选择尽量用底部弹层，不跳页
训练日选择是底部 sheet，选完原地返回，不打断上下文。
→ **规则：轻量选择不进新页。** 我们暂未做 sheet（当前用 Segmented 与胶囊替代），列入 v0.7 候选。

### R10 · 分段控件用于"同一份数据的三种看法"
「全部 / 近 30 天 / 近 7 天」不改页面结构，只改数据窗口。
→ **规则：Segmented = 时间窗，不是导航。** 我们：图谱页「全部 / 近 30 天 / 近 7 天」。

### R11 · 没有阴影，靠底色层级 + 1dp 描边分层
纯黑底 + #1C1C1E 卡片 + 1px 分隔线，圆角 16–20，间距 12/16。
→ **规则：层级靠"底色差 + 细描边"，不靠投影。** 我们：暖白纸感 Paper / Card / Card2 三层 + `Look.Hair` 描边 + 16dp 圆角。

### R12 · 强调色只做两件事：主 CTA 和"有意义的数字"
绿色从不用于装饰性图形。热力格的四档深浅也只在"有数据"时上色，0 值用底色。
→ **规则：颜色 = 信息，不是装饰。** 我们：`Look.Accent` 只给主按钮与选中态；热力格 0 值用 `Look.Track`；时段画像无数据时不画空槽（v0.6 修正，避免"满格空条"被误读）。

## 三、我们没有照搬的三件事（以及理由）

| 不照搬 | 理由 |
|--------|------|
| 纯黑底 + 荧光绿 | 上一版就是"深蓝黑 + 霓虹薄荷绿"，用户明确反馈"太 AI 味"；且我们的使用场景常在白天户外、自习室强光下，深底反而难读 |
| 健身语境（组数/重量/1RM） | 我们的单位是"5 分钟能做完的小事"，不是重量与次数；参数调节对应改成"时长胶囊" |
| 大媒体区（动作动画） | 我们没有动作演示素材；改成「汉字贴纸 + 一句 cue」，靠文字把"第一步怎么做"说清楚，避免假动画 |

## 五、这套规则怎么用到答辩里

1. **说明我们不是随手堆界面**：12 条规则都是从真实产品的画面反推的，且每条都有"为什么"。
2. **说明我们做了取舍**：三条不照搬，理由写清（配色、语境、素材），体现判断力而不是模仿。
3. **说明规则可验证**：R6 的"胶囊换行导致大块空白"是我们自己踩过并修掉的（v0.5 → v0.6），有截图前后对比。
