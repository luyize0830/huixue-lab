## 1 项目概述

### 1.1 项目背景

缺的不是知识，是决策：知道该歇，却不知做什么。手环只给分数、打卡不判断；本项目把五步压进一次 5 分钟实验。

### 1.2 项目定位

| 维度 | 内容 |
| --- | --- |
| 场景 / 人群 | 图书馆写论文、期末周熬夜、宿舍刷手机；18–24 岁在校生，手环可选 |
| 非目标 | 健康报告、疾病筛查、情绪诊断、社交排行、云同步 |

### 1.3 项目方案

五步：理解处境（规则扣分→分档与依据）→ 方案（Beta+约束→2–3 候选带理由）→ 行动（倒计时+振动）→ 反馈（1–5 分+心率差）→ 沉淀（画像/榜单/CSV/清空）。

### 1.4 目标与价值

可验收：真机心率、推荐即时、CSV 与清空；访谈试用未验收。

## 4 需求分析

### 4.1 数据需求

静态：26 条行动（MOVE/CALM 各 5，其余 4）、四时段、阈值。

心率/静息（`0x2A37`、1 s；静息取会话最低）、专注/屏幕（`UsageStatsManager`）、久坐（步数差分）；缺失为 null 跳过。字段：`heartRate`/`restingHr` 30–250、`focusMinutes` 0–600、`screenMinutesLastHour` 0–60、`sedentaryMinutes` 0–1440。

采集：心率仅前台；统计在 `onResume` 与唤醒查；步数差分。

### 4.2 功能需求

| 编号 | 功能 | 描述 | 优先级 |
| --- | --- | --- | --- |
| F-01..F-04 | 评估、推荐、计时、评分 | 算分与依据；2–3 候选带理由；倒计时；1–5 分+心率写 `records_v1` | P0 |
| F-05..F-10 | 池、图谱、导出、对话、提醒、深夜 | 增删、画像、CSV、解析、通知、时段过滤 | P1 |
| F-11/13/F-18..24 | 信号、扩展与结构 | BLE/统计/计步；陪练/语音/HC；底栏/页签/详情；扫描/授权/我的/性格 | P0–P2 |

### 4.3 性能需求

推荐 <50 ms（内存计算，待基准）、心率跟随 notify（实测 1 s 级）、冷启动 <2 s（待补）。无网络可用；深色与字号未适配。

### 4.4 界面需求

令牌在 `ui/Look.kt`，结构在 `ui/Tabs.kt`（见 09）。组件：自绘 `Glyph`、汉字贴纸、`StatCard`；空态给出口、胶囊单行滚动。登录页全屏、称呼必填、写明「这不是账号系统」。

### 4.5 接口需求

硬件：HRS `0000180d-…` / `00002a37-…` / CCCD `00002902-…`（写 `01 00` 开 notify）；flags bit0=0 → 1 字节，=1 → 2 字节小端。

软件：`UsageStatsManager`、`TYPE_STEP_COUNTER`、`AlarmManager`、`NotificationManager`、`SharedPreferences`、`FileProvider`+CSV、`RecognizerIntent`、`AudioTrack`。

### 4.6 其他需求

离线优先：默认不联网，仅可选 DeepSeek 对话需 `INTERNET`；本地账号无密码；不采位置与通讯录。

### 4.7 对话链路与真人感（v0.11–v0.17）

发模型仅当前句+最近 6 轮+行动目录（不含心率与记录）；记忆 40 轮+摘要，失败退回本地。回复拆 1–3 条（≤30 字、丢客服腔、去句号）；首条 1200–2600 ms 按字数与情绪浮动，间歇 600 ms；连发合并 8 s、半句 +4 s、14 s 必回；`minutesSinceLast` 进提示词；人设每 4 轮重注。

### 4.8 提示词工程（v0.14）

语气用"示例对照"（他：今天好累 / 你：嗯……累啊）而非规矩清单，`actionIds` 默认空；五档预设 + 自定义存 `PersonaStore`，原样进 prompt、只发用户自己的模型，未接入不生效。

### 4.9 主动找人（v0.18）

`Initiative.maybeReach` 六条：久未聊（≥70 分 3 h、<70 分 2 h）、冷却 60 min、日上限 3、23:00–07:00 静默、有未读不叠、检查 20 min；`lastTalkAt == null` 返回 false。

句子三段：时段开场 + 她的事 + 追问（有 note 用「上次你说「X」，后来呢？」，否则「在干嘛呢？」）；担心态一句。

边界：`llmKey.isNotBlank()` 才调——没接模型不主动（BUG-24）。

### 4.10 语音输出（v0.19）

| 决定 | 理由 |
| --- | --- |
| 系统 TTS | 不打包音色、不要录音权限、不上传音频 |
| 默认关 | 突然出声比安静吓人 |
| >120 字截断 | 念两分钟像导航 |
| 离开即 `shutdown` | 后台念稿是最尴尬的陪伴 |
| 失败写明原因 | 无引擎/无中文包不静默失败 |
| 喇叭只在开启时出现 | 关掉不留装饰 |

只念新消息；可重听，`flush = true` 打断上一句。

### 4.11 压力与情绪推断（v0.20）

`StressEngine`（纯函数）以 HRV 为主：RMSSD <20/30/45 扣 40/26/12；心率高出基线 ≥20/12/6 扣 24/14/6；专注 ≥120/90 扣 10/6；深夜扣 8；屏幕 ≥50 分钟扣 6。score 越高越紧：<35 放松、<60 有点紧、≥60 偏紧；无生理数据 UNKNOWN，界面写「按作息和行为估的」。情绪顺序先生理、再作息、最后兜底；界面写「看起来/推断」，依据可展开。

### 4.12 音乐与第三方绑定（v0.20）

三段音景由 `AudioTrack` 实时合成（22050 Hz、单声道、PCM16）：雨（多频正弦噪声 + 慢 LFO + 每 1.7 s 雨滴）、风（F3/A3/C4 轻 detune 拍频）、呼吸（C3/G3 + 10 秒包络）。不含音频文件，无版权风险、不增包体；离开页面即停，无前台服务。推荐只在偏紧时白天推，半夜只在还醒着且不放松时推，两次隔 90 分钟。`MusicBinding` 只记常用 App、把「轻音乐」放剪贴板并一键跳转（QQ 音乐试深链，失败退回打开 App），不做逆向、不自动播放——第三方没有公开播放接口。

### 4.13 模型接入的失败可见性（v0.21/v0.22）

`askOutcome()` 返回 `LlmResult`：`Ok`、`Fail(reason)`、`NOT_CONFIGURED`。`LlmErrors`（纯函数）把错误翻成人话：400 模型名、401 Key、402 余额、403 权限、404 地址、429 太频繁、5xx 服务端；异常侧 UnknownHost→域名、SocketTimeout→没回应、SSLException→应用 https、ConnectException→连不上；非 JSON→「没看懂」。界面：失败气泡后缀写原因，输入框上方提示条 +「改设置 →」进 `ModelSetupScreen`；「我的」删掉只填 Key 的弹窗，改成「模型已接入 / 设置」整卡，地址、模型名、Key 同页改。未接入写「还没接入」，不写「连不上」。

## 8 详细设计（核心算法）

### 8.1 状态评估（StateEngine）

| 信号 | 条件 | 扣分 |
| --- | --- | --- |
| 心率抬升 | ΔHR ≥ 15 / ≥ 8 | 22 / 10 |
| 连续专注 | ≥120 / ≥90 / ≥60 分钟 | 18 / 12 / 6 |
| 时段 / 屏幕 | `hour ≥ 23` 或 `< 5` / 近 1 小时 ≥ 40 分钟 | 15 / 8 |
| 久坐 | ≥90 / ≥60（null 跳过） | 12 / 6 |

```
penalty = Σ 命中规则
score   = (100 - penalty).coerceIn(5, 100)
band    = score < 40 ? LOW : score < 70 ? MID : HIGH
```

### 8.2 推荐（Recommender）

按行动×档位统计 s（≥4 分）与 n，α=1+s、β=1+(n−s)；采样前 3，零样本 +0.18；约束：时长 → 深夜只留 REST/CALM/FUEL（不足回退）→ 排除 id → 场景。

### 8.3 意图解析（IntentParser）

情绪（累/烦/空/还行）、场景（宿舍/图书馆/教室/路上/未知）、预算（分钟，无单位或"一会儿"按 5）走关键词与数字槽位。

### 8.4 提醒决策（NudgePlanner）

分数 <55 或久坐 >60 分钟、距上次 ≥50 分钟才通知；`AlarmManager` 每 30 分钟唤醒。

### 8.5 洞察统计（InsightsEngine）

四时段聚合次数/均分/心率差；榜单按均分降序、同分按次数；有效率 = 评分 ≥4 占比；CSV 按 RFC 4180。

### 8.6 陪练码（Pairing）

40 bit：版本 3+分钟 6+id 哈希 15+epoch 分钟低 16，Base36 8 位（`XXXX-XXXX`）；按 16 bit 窗反推；2 小时有效、不联网。

### 8.7 实验报告的口径设计（ExperimentReport）

两表聚合（类别/时段），口径写死：`MIN_GROUP = 3`（<3 次只列不排名）、心率前后都要有值、页末「N=1，不可外推」；`org.json` 不可单测，故写 `JsonLite`。
