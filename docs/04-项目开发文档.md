## 1 项目概述

### 1.1 项目背景

缺的不是知识，是决策：知道该歇，却不知做什么。手环只给分数、打卡不判断；本项目把五步压进一次 5 分钟实验。

### 1.2 项目定位

| 维度 | 内容 |
| --- | --- |
| 场景 / 人群 | 图书馆写论文、期末周熬夜、宿舍刷手机；18–24 岁在校生，手机必需、手环可选 |
| 非目标 | 健康报告、疾病筛查、情绪诊断、社交排行、云同步 |

### 1.3 项目方案

五步：理解处境（五规则扣分→分档与依据）→ 提供方案（Beta+约束→2–3 候选带理由）→ 行动（倒计时+振动）→ 反馈（1–5 分+心率差）→ 沉淀（画像/榜单/CSV/清空）。

### 1.4 目标与价值

可验收：真机心率、推荐即时、CSV 与清空；访谈试用未验收。

## 4 需求分析

### 4.1 数据需求

静态：26 条行动（MOVE/CALM 各 5，其余 4）、四时段、阈值常量。

心率/静息（BLE `0x2A37`、1 s 级；静息取会话最低）、专注/屏幕（`UsageStatsManager`）、久坐（步数差分）；缺失为 null 并跳过。字段：`heartRate`/`restingHr` 30–250、`focusMinutes` 0–600、`screenMinutesLastHour` 0–60、`sedentaryMinutes` 0–1440。

采集：心率仅前台；统计在 `onResume` 与唤醒查；步数差分。

### 4.2 功能需求

| 编号 | 功能 | 描述 | 优先级 |
| --- | --- | --- | --- |
| F-01..F-04 | 评估、推荐、计时、评分 | 算分与依据；2–3 候选带理由；倒计时；1–5 分+心率写 `records_v1` | P0 |
| F-05..F-10 | 池、图谱、导出、对话、提醒、深夜 | 增删、画像、CSV、解析、通知、时段过滤 | P1 |
| F-11/13/F-18..24 | 信号、扩展与结构 | BLE/统计/计步；陪练/语音/HC；底栏/页签/详情；扫描/授权/我的/性格 | P0–P2 |

### 4.3 性能需求

推荐 <50 ms（内存计算，待基准）、心率跟随 notify（实测 1 s 级）、冷启动 <2 s（待补）。

适应性：无网络可用；深色与字号未适配。

### 4.4 界面需求

令牌在 `ui/Look.kt`，结构在 `ui/Tabs.kt`（规则见 09）。组件：自绘 `Glyph` 8 类、汉字贴纸、`StatCard`；空态给出口、胶囊单行滚动。登录页全屏、称呼必填、写明「这不是账号系统」。

### 4.5 接口需求

硬件：HRS `0000180d-…` / `00002a37-…` / CCCD `00002902-…`（写 `01 00` 开 notify）；flags bit0=0 → 1 字节，=1 → 2 字节小端。

软件：`UsageStatsManager`、`TYPE_STEP_COUNTER`、`AlarmManager`、`NotificationManager`、`SharedPreferences`、`FileProvider`+CSV、`RecognizerIntent`。

### 4.6 其他需求

离线优先：默认不联网，仅可选 DeepSeek 对话需 `INTERNET`；本地账号无密码；不采位置与通讯录。

### 4.7 对话链路与真人感（v0.11–v0.17）

`ChatContext` 打包 hour/band/mood/记忆/天数/历史；发模型仅当前句+最近 6 轮+行动目录（不含心率与记录）；记忆 40 轮 + 摘要，坏行跳过，失败退回本地。回复拆 1–3 条（每条 ≤30 字、丢客服腔、去句号）；首条深夜 2600/早 1800/白天 1200 ms，间歇 600 ms + 0.35–0.75 倍（`Rhythm`）。连发合并 8 s、半句 +4 s、14 s 必回；`minutesSinceLast` 进提示词；人设每 4 轮重注（`FULL_INJECT_EVERY = 4`）。

### 4.8 提示词工程（v0.14）

语气用"示例对照"（他：今天好累 / 你：嗯……累啊）而非规矩清单，`actionIds` 默认空；五档预设 + 自定义存 `PersonaStore`，原样进 prompt、只发用户自己的模型，未接入不生效。

### 4.9 主动找人（v0.18）

`Initiative.maybeReach` 六条：久未聊（≥70 分 3 h、<70 分 2 h）、冷却 60 min、日上限 3、23:00–07:00 静默、有未读不叠、检查间隔 20 min；`lastTalkAt == null` 返回 false。

句子三段：时段开场 + 她的事（6 句池）+ 追问（有 note 用「上次你说「X」，后来呢？」，否则「在干嘛呢？」）；担心态一句。

边界：`llmKey.isNotBlank()` 才调——没接模型不主动（BUG-24）。

### 4.10 语音输出（v0.19）

| 决定 | 理由 |
| --- | --- |
| 系统 TTS | 不打包音色、不要录音权限、不上传音频 |
| 默认关 | 第一次见面突然出声比安静吓人 |
| >120 字截断 | 念两分钟像导航不像人 |
| 离开即 `shutdown` | 后台念稿是最尴尬的陪伴 |
| 失败写明原因 | 没引擎/没中文包不静默失败 |
| 喇叭只在开启时出现 | 关掉不留装饰图标 |

只念新消息；可重听，`flush = true` 打断上一句。

## 5 概要设计

### 5.1 处理流程

```
信号 → SensorSnapshot → 状态分/档位
      Recommender.recommend → 候选(≤3) → Timer → Feedback
      ExperimentRecord → Store(records_v1) → InsightsEngine / CSV
```

### 5.2 总体结构

| 层 | 职责 | 文件 |
| --- | --- | --- |
| UI | 12 屏、导航、状态收集 | `ui/App.kt`、`ui/Tabs.kt`、`ui/ReportScreen.kt` |
| 领域 | 纯逻辑 | 五引擎 + 陪练/HRV/报告/模型/角色/主动 |
| 数据 | 持久化与取数 | `Repo.kt`、`Store.kt`、统计/计步、BLE、`LlmClient.kt`、`ChatMemory.kt` |
| 入口 | 权限、生命周期、调度 | `MainActivity.kt` |

### 5.3 功能设计

六组页面：今天/推荐（状态分、依据、2–3 卡）；回血池/详情（搜索+胶囊+列表，详情五段）；计时/反馈（倒计时、1–5 分与心率差、8 位码）；图谱（数字卡、热力格、画像、时间窗、CSV）；对话（头像+开场+一句话→回显→方案）；我的/搜索（账号、设备、陪练码、导出、清空、扫描、认脸/接入/性格页）。

### 5.4 数据流转

取数只产 `SensorSnapshot`；记录写 `Repo.records`。

### 5.5 数据结构

四类数据：快照、评估、行动、记录（行动/档位/前后心率/评分/时间）；字段见 4.1，统计见 8.5。

### 5.6 接口设计

内部契约：`assess`/`recommend`/`parse`/`shouldNudge`/`summary`。

### 5.7 错误与异常处理

| 场景 | 提示 | 对策 |
| --- | --- | --- |
| 未授权 / 断连 | 提示重试 | 心率置空；统计记 0；通知失败留入口 |

versionCode 随功能递增、versionName 走小版本（当前 20 / 0.19）；debug 为 test-only（`adb -t`）；release 签名与混淆未配置。分层：`logic` 纯逻辑、`data` 取数存储、`ui` 页面与令牌。

## 8 详细设计（核心算法）

### 8.1 状态评估（StateEngine）

| 信号 | 条件 | 扣分 |
| --- | --- | --- |
| 心率抬升 | ΔHR ≥ 15 / ≥ 8 | 22 / 10 |
| 连续专注 | ≥120 / ≥90 / ≥60 分钟 | 18 / 12 / 6 |
| 时段 / 屏幕 | `hour ≥ 23` 或 `< 5` / 近 1 小时 ≥ 40 分钟 | 15 / 8 |
| 久坐 | ≥90 / ≥60（null 跳过） | 12 / 6 |

```
penalty = Σ 命中规则
score   = (100 - penalty).coerceIn(5, 100)
band    = score < 40 ? LOW : score < 70 ? MID : HIGH
```

### 8.2 推荐（Recommender）

按行动×档位统计 s（≥4 分）与 n，α=1+s、β=1+(n−s)；采样前 3，零样本 +0.18；约束：时长 → 深夜只留 REST/CALM/FUEL（不足回退）→ 排除 id → 场景。

### 8.3 意图解析（IntentParser）

情绪（累/烦/空/还行）、场景（宿舍/图书馆/教室/路上/未知）、预算（分钟，无单位或"一会儿"按 5）均走关键词与数字槽位。

### 8.4 提醒决策（NudgePlanner）

分数 <55 或久坐 >60 分钟、距上次 ≥50 分钟才通知；`AlarmManager` 每 30 分钟唤醒。

### 8.5 洞察统计（InsightsEngine）

四时段聚合次数/均分/心率差；榜单按均分降序、同分按次数；有效率 = 评分 ≥4 占比；CSV 按 RFC 4180。

### 8.6 陪练码（Pairing）

40 bit：版本 3+分钟 6+id 哈希 15+epoch 分钟低 16，Base36 8 位（`XXXX-XXXX`）；按 16 bit 窗反推；2 小时有效、不联网。

### 8.7 实验报告的口径设计（ExperimentReport）

两表聚合（类别/时段），口径写死：`MIN_GROUP = 3`（<3 次只列不排名）、心率前后都要有值、页末「N=1，不可外推」；`org.json` 不可单测故写 `JsonLite`。
