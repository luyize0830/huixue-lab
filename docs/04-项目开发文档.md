# 《回血实验室》项目开发文档

> 当前交付：v0.27 / versionCode 28；代码基线 `656c368`；JVM 267 例、网页 24 例通过；安卓设备测试 7 例在真机与模拟器各通过一次。正式 APK 4,625,098 字节，兼容升级 APK 18,754,270 字节。日期：2026-11-18；详见 [验证记录](v0.27-validation.md)。

## 1 项目概述

产品定位是个人微行动实验助手。五步流程：理解处境、提供候选、执行行动、记录反馈、形成个人观察。首页推荐不超过 5 分钟，完整行动池支持 1–10 分钟；包名保持 com.example.blehr。

## 2 开发计划

Android 主程序用于真实采集，网页用于免安装演示。F-01–F-38 保留历史编号；F-39 计时恢复、F-40 行动管理、F-41 备份恢复、F-42 睡眠评分、F-43 推荐轮次记录。验收包括 JVM/网页、原生备份、实际界面接线、签名与安装，详情见验证记录。

## 3 可行性分析

标准 BLE HRS 已有历史验证，本轮完整真实读数链路仍待复核。无可用数据时界面降级。只有纯逻辑单测无法发现页面漏传心率，故增加真实 Compose 界面测试；不以测试数量代替业务效果证据。

## 4 需求分析

### 4.1 数据需求

| 信号 | 来源和边界 |
|---|---|
| 心率、参考基线 | BLE notify；基线为最近 30 次读数最小值，非医学静息心率 |
| 连续使用、近一小时屏幕 | UsageStatsManager；没有授权时使用带标注的演示输入 |
| 没走动时长 | 手机步数变化；站立不动可能被算入 |
| 昨夜睡眠 | Health Connect 会话记录；按本地昨18点至今12点裁剪，重叠合并、分段累加 |
| 反馈 | 用户自评 1–5 与可选前后心率；保留行动开始时的快照 |

睡眠统计的是记录会话时长，不保证排除全部夜间觉醒；缺失返回 null。读取会遍历分页，步数使用聚合接口，避免直接累加多数据源。

### 4.2 功能与界面需求

今天、推荐、计时、反馈、回血池、图谱、我的构成主流程；聊天、设备、报告、备份为辅助页面。首页/提醒共用实时快照；演示模式不触发真实状态提醒。推荐页每批候选只记一轮，重组不重复计数。

### 4.3 性能与接口需求

原生页面采用 Compose；模型请求设连接与读取超时，错误显示原因并提供设置入口。性能目标尚无完整低端机压测数据，不填写未经测量的帧率或耗电数字。

### 4.4 用户控制与数据边界

提醒可关、行动可编辑/归档、记录可清空；备份导入先校验并可撤销。可选模型会接收输入、最近对话、角色/记忆和行动上下文；不应笼统宣称全应用永不联网。Key 保存在应用私有偏好中，业务导出排除它。

## 5 概要设计

UI 观察 Repo 不可变快照；logic 负责状态、采样、会话、报告与编码；data/ble 负责存储和平台接口。刷新协程只更新数据源，评估与主动陪伴由当前重组状态触发，避免常驻协程捕获旧输入。

异常路径包括无权限、无 HRS、无健康记录、模型超时、存储失败、错误备份。均保留本地流程或明确拒绝操作，不用虚构数据填空。通知闹钟不随每次分数变化重新推迟；进程被终止时仍不保证准点计时通知。

## 6 数据存储设计

SharedPreferences 中单值 snapshot_v2 保存行动、历史、收藏、归档、会话及推荐轮次，先 commit 再发布 UI。推荐记录含轮次号、展示时间、候选、档位、演示标志、选择/跳过、会话号；最多 5000 轮。选择与新会话原子保存，反馈用会话号去重。

旧快照缺少推荐字段时读取为空，不倒推曝光。备份沿用版本1的向后兼容可选字段；仍严格校验已提供的内容。跨偏好恢复通过导入前副本与标记支持中断恢复。清空记录同时清空推荐轮次，导入前副本可另行删除。

## 7 手机端侧部署设计

Android minSdk 26、target/compile 37。使用本机持久发布签名生成 release 包；旧 debug 安装使用同签名兼容包。签名与密码只从环境变量读取，不提交私钥；新旧签名不同，禁止为测试自动卸载已有数据。

## 8 详细设计

### 8.1 状态评估

心率相对基线 ≥15/8 分别扣22/10；连续使用 ≥120/90/60 扣18/12/6；深夜扣15；近1小时屏幕 ≥40 扣8；没走动 ≥90/60 扣12/6；睡眠 <5/6/7 小时扣16/10/5。100减扣分后限制5–100；<40低、<70中，其余高。阈值属于经验产品规则。

### 8.2 推荐与统计

先按时间/排除/场景过滤，深夜优先 REST/CALM/FUEL；候选不足仍有原有回退规则。每个行动×档位采样 Beta(1+评分≥4次数,1+其余次数)，冷启动加0.18。心率差不参与成功标签。

F-43 接受率=真实选择/真实展示；反馈完成率=有关联反馈的真实选择/真实选择。分母为0显示 —。离开或换批标跳过；进程直接终止可能保留未决 SHOWN，不伪造拒绝。网页事件全部 DEMO；旧网页缺档位的评分保留统计但不用于分档学习。

## 9 构建与运行

JDK25、Android SDK37；运行 gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest、node web-demo/selftest.js，以及 python tools/check_delivery.py --require-unit-reports。发布签名参数见 RELEASE.md。

真实 Health Connect 睡眠链路、长时锁屏/Doze通知、真实模型和 TTS 本轮仍待专项复验；用户访谈试用尚未完成。HRV/压力为探索性推断，不作医学诊断。历史设计和缺陷保留在 Git 与 defect-history.md。
