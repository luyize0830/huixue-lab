# 《回血实验室》设计及创新性分析报告

## 1 痛点分析

### 1.1 痛点概述

痛点在三个层次。决策："休息一下"不是可执行指令，做什么、多久都没给。证据：手环只给分数，不解释、不对应动作、做完没记录，下次从零开始。归属：任务多是系统派的，没认同感。结果是知道该停，却停在刷手机上。

### 1.2 相关工作

厂商方案（WHOOP、Oura、Garmin、Apple）传感器做到极致，建议却是通用最佳实践加生理分数，与当下处境（图书馆、3 分钟、不能说话）无关。番茄钟与精力快充给结构不给判断；冥想类给动作不给选择；JITAI 有框架但需团队与设备。缺口同一个：没有工具把"我的状态、我的选项、我的历史"放在一张表上。

## 2 项目创新点

### 2.1 交互设计与信息架构

v0.6 起导航不再把入口堆在首页，而是常驻底栏四格（今天/回血池/⚡/图谱/我的）+ 中央 52 dp 主按钮；信息架构仍按五步闭环组织，共 12 屏。

| 层级 | 页面 | 承担的闭环环节 | 关键约束 |
| --- | --- | --- | --- |
| 入口 | 今天 | 理解处境 | 3 秒看懂状态，依据可展开 |
| 决策 | 推荐 | 提供方案 | 2–3 张卡，每张一句理由 |
| 行动 | 计时 | 用户行动 | 全屏，只有一个主操作 |
| 校准 | 反馈 | 反馈校准 | 5 个按钮，3 秒完成 |
| 沉淀 | 图谱 | 长期沉淀 | 先数字卡，再热力格，最后明细 |
| 素材 | 回血池 / 动作详情 | 候选来源 | 搜索 + 胶囊 + 行列表；详情按贴纸 → 标签 → cue → 开始 |
| 辅助 | 对话 | 快速入口 | 一句话 → 方案，回显可改 |
| 辅助 | 加入陪练 | 行动同步 | 粘 8 位码，与对方同一起点 |

三条交互原则：每步决策 ≤3 秒；不打断（提醒可关，冷却 50 分钟）；结论可点开看依据。

### 2.2 主页面与辅助入口的设计意图

首页：回答"我现在怎么样"，结论 + 分数 + 可展开依据；未授权明示演示数据。

推荐：回答"现在做什么"，卡片只放标题、分钟、分类与一句理由。

计时：全屏倒计时 + 结束按钮，结束振动；不显示心率曲线，避免盯数字焦虑。

反馈：回答"有没有用"，1–5 分 + 自动带出的心率差，不做长表单。

图谱：回答"哪种方式对我有效"，先时段画像与总结，再榜单、CSV 与清空。

回血池与「我的」各占底栏一格；对话与扫描是入口：前者降低"不想点卡片"的门槛，后者解决连不上手环。

v0.7 可用性判断（工程取舍）：设备与授权收进「我的」并带状态 chip；手环搜索独立成页；HC 按三态分流。

### 2.3 为什么要"可展开依据"

可展开依据解决三件事：可信（能看到哪条规则扣分）、可争（用户能不同意，比如心率高是刚爬楼）、可校（能定位是规则错还是取数错）。折叠默认、展开可退——这是"实验助手"与"教练"的分界。

### 2.4 AI 能力边界：哪里用，哪里刻意不用

用 AI 的地方：状态评估（多信号加权）、动作选择（Beta 后验采样 + 探索）、约束求解（时长/场景/深夜）、统计归纳。

刻意不用的地方：不诊断（不说"你焦虑"）、不做长程预测（不说"你明天会累"）、默认不用大模型生成建议（v0.9 起可自愿开）、不自动执行。

推荐与解析留在端上：采样式在线学习、关键词槽位解析，换来理由可追溯、可离线、可单测；模型只用于对话，失败退回本地。

### 2.5 界面刻意去模板化

v0.5 把"深色底 + 薄荷绿 + emoji"改成暖白纸感，图标 Canvas 自绘，分类用汉字贴纸，反馈页改文字。理由：①强光下深色底难读；②深蓝黑配霓虹绿是生成式观感；③17 dp 线稿辨识度低；④不引图标库。

这与第 5 条（用户可控、易理解）相关：去模板化不是审美，是让"实验记录工具"在视觉上成立。截图 `evidence/v05-home-06.png`、`v05-pool-04.png`。

### 2.6 界面规则的反向推导

v0.6 结构反推：六屏真实截图整理成 12 条规则，再按本项目重写。R1 全局一个实心主按钮；R2 名词进底栏、动词进中心；R3 先大数字再热力格再明细；R4 一格答一问；R5 空态给出口；R6 胶囊单行可滚动；R7 行三块固定；R8 详情顺序固定、末尾灰字口径；R9 轻选择用弹层（未做）；R10 分段控件只改时间窗；R11 层级靠底色差与 1 dp 描边；R12 强调色只给主 CTA 与有意义的数。

三条不照搬：①纯黑底 + 荧光绿（强光难读）；②健身语境（组数/重量→"5 分钟能做的小事"）；③大媒体区与动画（改汉字贴纸 + 一句 cue）。规则可借，语汇不能借。

与第 5 条的关系：规则让"下一步点哪"清晰，而非替用户决定；每屏能看到来源、改筛选、退上一步。

界面约束（v0.9）：报告页把口径印在页面上——<3 次只列不排名、N=1 不可外推；HRV 样本不足显示"正在攒"。v0.9.1 补：Key 不合格当场拒存，连不上写明是本地规则给的。

**角色阈值 = 产品的态度。** 档位如实汇报，角色（担心 <70、开心 ≥85）提前一步劝；67 分"还有余量、她已在担心"不矛盾——提醒早于告警。

**陪伴不是语气软，是记得你。** 记忆只留 40 轮与一句摘要，下次能接上"上次聊到"；当天首次打开先开口；`actionIds` 为空只回话不摆卡。三条都把"角色"当约束。

**入口即功能：找不到的开关等于没有。** v0.12 把地址/模型/Key 从「我的」第三屏抽成独立页：此前未接入时角色卡整张隐藏，用户以为没选项。v0.13 称呼做成必填。都是把用户此刻的决定放到眼前。

**把语气交给用户，是把选择权留在人手里。** v0.14 的「她的性格」不是皮肤商店：五档可选、也能自写，原样进 prompt、只发自己的模型。默认档刻意"不喊加油、不装医生"：默认值就是态度。页面写明"没接模型不生效"。

**克制"陪伴"的两种假象：不回 ≠ 高级，秒回 ≠ 真诚。** 参考项目超时默认不回，但陪伴产品的沉默即失约。v0.17 折中：8 秒内合并、半句多等 4 秒、14 秒必回，等待显示「正在输入…」；也不秒回：首条 1.2–2.6 秒、间歇 600 ms 起。

**主动不是频次，是说得像她。** v0.18 的主动找人只做三件事：有上限（一天 3 次、间隔 60 分钟）、有安静时段（23–7 点不打扰）、有她自己的事（洗杯子、手机没电…再追问"上次你说「在赶报告」，后来呢？"）。状态 <70 时 2 小时来找，≥70 时 3 小时。不主动像工具，主动过头像骚扰——这条线由常量写死、12 例钉住。

**会说话不是加音效，是把"我在"变成听得见。** v0.19 语音只做三件克制的事：默认关（手机突然开口比安静更吓人）、离开对话页立刻停（后台念稿最尴尬）、念不出来写明原因。不追求"真人感"，只求"我在"能被听见——仍是第 5 条：能关、能停、知道为什么没成。

**把"打扰"做成可算的规则。** v0.20 的音乐推荐只在真偏紧（HIGH）时白天推；半夜（23–5 点）只有还醒着（近一小时屏幕 ≥10 分钟）且不放松时才推；两次至少隔 90 分钟；关掉开关彻底不推；状态未知就不推。陪伴产品最易死在打扰，而非不推。

### 2.7 创新性论证

技术性：个性化落在端侧小样本贝叶斯更新而非云端大模型；主观评分与心率差进同一条记录，避免只用其一；约束先过滤再采样。

功能性：回血池把候选交给用户，解决"系统派任务没认同感"；3 秒评分压低成本；CSV 与清空明确数据归属；陪练码用 8 位字符换"一起做"，不要服务端。

其他：明确"不做健康报告"，把"实验助手"贯彻到文案。
