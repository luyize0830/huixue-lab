## 1 研究问题与预注册假设

### 1.1 研究问题

在真实的学习生活里，App 推荐的 5 分钟微行动，是否让"当下更回血"？哪一类行动、哪一个时段更可能有效？把这个问题拆成三个可测量的子问题：Q1 单次行动后的主观有效分怎么分布；Q2 不同类别在"心率下降"上的方向是否不同；Q3 深夜与白天的有效分是否不同。

### 1.2 预注册假设

| 编号 | 假设（可证伪） | 判定口径 | 结果 |
| --- | --- | --- | --- |
| H1 | 做完 4-7-8 呼吸等 CALM 类行动后，主观有效分均值 ≥ 3.5 | 取 CALM 类全部样本的有效分算术均值，<3.5 即不成立 | （待填） |
| H2 | 起身类（MOVE）行动后心率下降 ≥5 bpm 的比例，高于屏幕娱乐类（PLAY） | 分别算两类中"后心率−前心率 ≤ −5"的占比并比较；方向相反或相等即不成立 | （待填） |
| H3 | 深夜（23:00–6:00）可行动作的平均有效分，低于白天（6:00–23:00） | 两个时段有效分均值之差；深夜不低于白天即不成立 | （待填） |

**以上假设在看到任何数据之前写下，冻结为本文件 v0.1，避免事后挑结论（防 p-hacking）。** 数据收完后不新增假设、不改判定阈值，只允许在第 6.4 节登记执行偏差；报告时先给全部样本，再给分组，不得只挑支持假设的子集。

### 2.2 干预与对照

| 组别 | 定义 | 记录内容 | 用途 |
| --- | --- | --- | --- |
| 干预 | App 推荐或自选的 ≤5 分钟微行动，按计时完成 | 全字段（含行动前后心率、1–5 分） | 估计行动后的变化 |

## 3 测量与数据字段

### 3.1 字段表

| 字段 | 类型 / 取值 | 来源 | 缺失处理 |
| --- | --- | --- | --- |
| 时间戳 | 日期 + 时分（到分钟） | App 记录 | 缺失则整条作废 |
| 状态分 | 0–100 整数 | StateEngine 五规则扣分 | 缺失不补 |
| 档位 | 低 / 中 / 高（<40 / <70 / ≥70） | 同上 | — |
| 行动与类别 | 26 条之一；MOVE/CALM/SOCIAL/PLAY/REST/FUEL | 回血池 | 缺失则整条作废 |
| 行动时长 | 1–10 分钟 | 计时页 | 缺失按计划时长并标注 |
| 行动前心率 | 30–250 bpm | BLE 特征 0x2A37 实时值 | 无手环则空，该条不进 H2 |
| 行动后心率 | 同上 | 同上 | 同上 |
| 主观有效分 | 1–5（没用/一般/还行/有用/很管用） | 反馈页 | 缺失则整条作废（H1、H3 依赖它） |
| 场景 | 宿舍 / 图书馆 / 教室 / 路上 | 用户选择 | 缺失记"未标注" |
| 是否深夜 | 是 / 否（23:00–6:00） | 时间戳推导 | 自动 |
| 备注 | 自由文本（咖啡、爬楼、不适等） | 用户 | 可空 |

### 3.2 心率从哪来

App 通过标准 GATT 心率服务（服务 `0x180D`、特征 `0x2A37`）订阅通知，内存里保留最近 30 个样本；行动开始前与结束后各取一次最近值。这是**实时测量值，不是手环历史数据，也不来自 Health Connect**，所以只有"前后两个点"，没有连续曲线。误差来源：佩戴松紧、抬腕伪影、手环自身测量间隔；心率对行动的反应还有延迟，5 分钟窗口内的变化只能当方向参考，不能当效应量。

### 3.3 导出

CSV 由图谱页导出，字段与 3.1 对齐；导出的原始表另存一份并粘进附录 A，保证答辩时每个数字可回溯到具体一次记录。

## 7 效度与局限

| 局限 | 具体表现 | 影响 | 缓解 |
| --- | --- | --- | --- |
| N=1 | 只有一个人，作息与体质都特殊 | 不能外推到"大学生群体" | 只声称"对本人这 14 天"的观察 |
| 天花板效应 | 主观分容易挤在 4–5 分 | 均值差异被压缩，H1 容易"被支持" | 报分布不只报均值，并看心率方向 |
| 心率混杂 | 咖啡、爬楼、紧张、天气 | 心率差未必来自行动 | 备注标注，尽量同场景内比较 |
| 无盲法 | 知道自己正在实验 | 期待效应抬高评分 | 预注册 + 主动报告反例 |
| 样本小 | 40 次摊到 6 类 × 4 时段 | 很多格子 n<3 | 只列不排名，必要时并到类别层 |
| 自选择 | 状态差时才想起来做 | 样本偏向低分时刻 | 用"仅记录"条目做参照 |

结论表述上，**我们不做因果断言，只报告现象**："有效"指"这一次做完，主观分与心率往好的方向动了"，不等于疗效，也不能说"这个方法适合所有人"。

## 9 风险与伦理

| 项 | 处理 |
| --- | --- |
| 数据范围 | 只读心率与系统使用统计；不含位置、通讯录、消息 |
| 存储与上传 | 全部本地（SharedPreferences + CSV），App 无网络权限，不上传 |
| 删除权 | 图谱页"一键清空"随时删；实验可随时中止 |
| 医疗边界 | 不诊断、不给治疗建议；异常心率（>180 或 <40 bpm）只提示"读数异常，请确认佩戴或休息"，不做解读 |
| 身体不适 | 立即停止；不做憋气、剧烈运动类动作 |
| 知情 | 受试者即研究者本人，事前已知晓流程与风险 |
