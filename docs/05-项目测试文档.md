## 4 系统测试（历史，非本轮验证）

### 4.1 真机 BLE 验证

扫描连接手环 9 Pro → 发现 `0x180D`/`0x2A37` → 写 CCCD 开 notify，心率随呼吸波动（60–100），三问全过（详见 00）。

### 4.2 模拟器全流程

AVD 走完首页→对话→计时→打分→图谱→导出，无崩溃；无 BLE 走演示滑杆并打角标。

### 4.3 陪练码端到端

A 生成「听歌」4 分钟码 `1VZJ-BZD0`；B 输入同码，解析出同一行动与开始时刻，两端显示「陪练中 · 和对方同一秒开始」，剩余 02:58 同步；超 2 小时与非法字符报错、不崩。

### 4.4 结果与建议

BLE 已出清；陪练码证明"不建服务端也能同步"；稳定性**待补**。

### 4.5 历史模型、角色与音频验证

早期记录包括真实 Key 回复、断网降级、角色三态、主动消息及系统 TTS/AudioTrack 调用；这些是历史阶段结果，本轮未复验。当前模型解析有本机 HTTP 集成测试，真实服务、音色、设备权限和第三方跳转仍待人工验证；历史材料可从前版 Git 文档追溯。

| BUG-06（设计） | 深夜推社交行动 | 采样未接时段 | 深夜模式（23–5 只推 REST/CALM/FUEL）+「换一批」 |

## 6 覆盖率与未覆盖部分

当前 29 个测试类通过；行覆盖率未统计（未接 JaCoCo）。网页版已有操作验证；原生 UI、BLE、权限与通知仍需设备验证。`LlmClient` 已加入本机 HTTP 集成测试；真实模型未自动化；`ReportScreen`、`PersonaScreen`、`Speaker.kt`、`MusicScreen.kt` 属纯 UI。

未覆盖：多天记忆（仅单日复现）；纯聊天空 `actionIds` 样本不足；登录页无 UI 测试；五档语气仅人工观察；语音音色取决于语音包；音频听感与第三方跳转未自动化；第三方中转地址与模型名未实测；双人节奏不适用。

风险：原生界面与设备层未完成本轮验证。
