## 4 系统测试

### 4.1 真机 BLE 验证

扫描连接手环 9 Pro → 发现 `0x180D`/`0x2A37` → 写 CCCD 开 notify，心率随呼吸波动（60–100），三问全过（详见 00）。

### 4.2 模拟器全流程

AVD 走完首页→对话→计时→打分→图谱→导出，无崩溃；无 BLE 走演示滑杆并打角标。

### 4.3 陪练码端到端

A 生成「听歌」4 分钟码 `1VZJ-BZD0`；B 输入同码，解析出同一行动与开始时刻，两端显示「陪练中 · 和对方同一秒开始」，剩余 02:58 同步；超 2 小时与非法字符报错、不崩。

### 4.4 结果与建议

BLE 已出清；陪练码证明"不建服务端也能同步"；稳定性**待补**。

### 4.5 模型、角色与性格（v0.9.1–v0.14）

真实 Key 下模型回「三点还撑着…」并给 2 张卡；飞行模式由本地规则回，尾注「没连上模型…」。角色卡显示头像、名字与情绪，当天首次先开口、退出再进能接上；性格页五档 + 自定义存 `huixue_persona`（`PersonaTest`、`ChatCodecTest`、`PersonaPresetTest`）。

### 4.8 真人感三段（v0.15–v0.17）

三个纯函数：`Humanizer` 切 1–3 条、每条 ≤30 字、客服腔整句丢；`Rhythm` 首条延迟（深夜 2600/早 1800/白天 1200 ms，夹 500–5200）与条间歇；`ReplyGate` 合并 8 s、半句 +4 s、14 s 必回。实测两条差 81 ms 只回一条（9.2 s 后），显示「正在输入…」。

### 4.9 主动找人（v0.18）

seed 一条 4 小时前记录，启动 35 秒后出现 `pending_v1` 与通知；卡片「中午了。…上次你说「在赶报告」，后来呢？」，CTA 变「回她一句」（`InitiativeTest`：23–7 静默、60 分钟冷却、一天 3 次、没聊过不主动）。

### 4.10 语音输出的验证方式（v0.19）

TTS 是平台 IO，**不加单测**——只能验证"调了没调"，验证不了"念得好不好"。靠 logcat（`Synthesis request for locale zho-CHN…`、`TTS dispatch: cmn-cn-x-ssa…`）与 `v19-voice-on.png`、`v19-chat-speaker.png`；音色取决于语音包，只记"能调用、语言对"。

### 4.11 压力、情绪与音频的验证方式（v0.20）

`StressEngine` 与 `MusicSuggestion` 是纯函数，按表钉住：HRV <20/30/45 扣 40/26/12，心率差 ≥20/12/6 扣 24/14/6，专注 ≥120/90 扣 10/6，深夜 8、屏幕 ≥50 分钟 6；无生理数据 UNKNOWN（界面写「按作息和行为估的」）。音乐三道门：只在偏紧时白天推、半夜还醒着且不放松才推、关开关不推；`Synth` 4 例钉住三段音景。`dumpsys audio` 见 `piid:79 state:started sampleRate:22050` 与 `event:stopped`（`v20-music-playing.png`）。

### 4.13 失败路径的验证方式（v0.21/v0.22）

三种实测：**不填 Key** → `Fail(NOT_CONFIGURED)`，气泡写「还没接入模型」，不是「连不上」；**假 Key** → HTTP 401 → 「Key 不对」，提示条带「改设置 →」；**非 JSON** → v0.22 起当普通回复渲染（`LlmReplyParserTest` +4）。402/404/429/5xx 与域名/超时/SSL 由 `LlmErrorsTest` 11 例钉住，并断言文案不含「连不上」。如实说明：第三方中转地址与模型名未实测。

## 6 覆盖率与未覆盖部分

按类 25/25；按行**未统计**（未接 JaCoCo）。UI 层（`App.kt`、`Tabs.kt`、`ChatScreen.kt`）无自动化；BLE 无 Instrumented Test；权限与通知靠手工。`LlmClient` 手工验过，不适合 CI，**未进单测**；`ReportScreen`、`PersonaScreen`、`Speaker.kt`、`MusicScreen.kt` 属纯 UI。

未覆盖：多天记忆（仅单日复现）；纯聊天空 `actionIds` 样本不足；登录页无 UI 测试；五档语气仅人工观察；语音音色取决于语音包；音频听感与第三方跳转未自动化；第三方中转地址与模型名未实测；双人节奏不适用。

风险：逻辑层有回归，**界面与设备层全靠手工**，是最大短板。
