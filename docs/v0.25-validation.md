## 存储与备份边界

本轮保留 SharedPreferences，将行动、记录、标记和会话合并为 `snapshot_v2`，校验后同步提交，再发布界面状态。旧记录/行动只在迁移成功后移除旧键；历史条目补当时可获得的行动快照。

安卓备份版本 1，最大 8 MB；仅允许列明的档案、聊天、人设、语音、音乐和提醒选择。**不导出整个模型配置、密钥、设备标识或系统权限**；导入保留当前模型设置。导入前保存 AtomicFile 副本和标记，失败或下次启动发现未完成时恢复；可撤销导入，也可删除恢复副本。存在活动会话时先完成或取消，避免反馈被覆盖。

网页版保存本浏览器业务数据，使用独立平台标记，**Android 与 Web 备份不能互相导入**。重复导入采用整体替换，不做叠加合并。Room、云同步和第三方图表库未引入。
