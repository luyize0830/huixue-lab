# 《回血实验室》项目计划书

> 当前交付：v0.28 / versionCode 29；代码基线 `e0fb99f`；JVM 285 例、网页 24 例通过；安卓设备测试 14 例在隔离 Android 17 模拟器通过，未连接真机。正式 APK 4,641,482 字节，兼容升级 APK 18,773,593 字节。日期：2026-11-27（北京时间）；详见 [验证记录](v0.28-validation.md)。

## 1 项目概述

### 1.1 项目背景

面向在校大学生长时间学习后“知道该休息，却不知道此刻做什么、多久、是否有用”的场景。用户访谈与两周试用尚未完成；现阶段需求依据来自团队自用与技术验证，不引用虚构的用户百分比。

### 1.2 项目内容

手机行为与可选手环信号 → 可展开的状态依据 → 个人行动池中的微行动 → 计时与自评 → 个人记录与下一次推荐。首页推荐限定 5 分钟以内；行动池可管理 1–10 分钟行动。无手环仍可用；未授权使用统计时明确使用演示信号。

### 1.3 创新点

1. 以个人可执行行动池为候选，按时间、场景约束后再做端侧在线推荐。
2. 主观反馈更新“行动×状态档位”的 Beta 后验；心率参与状态评估及效果参考，不把心率下降直接等同成功。
3. 每条状态依据可展开；真实推荐与演示轮次分开统计，保留用户选择、退出、导出和删除能力。

## 2 技术方案

### 2.1 总体架构

Jetpack Compose 界面、纯 Kotlin 领域逻辑、本机数据与传感器三层。BLE 使用标准 HRS；使用统计来自 UsageStatsManager，久坐由步数变化近似，睡眠经 Health Connect 只读。状态快照在重组时更新，首页与主动陪伴共用同一次评估。

### 2.2 功能详述

已具备状态/推荐、计时恢复、反馈、行动管理、报告、CSV、完整备份、可选模型聊天、语音与音景。F-42 为睡眠评分；v0.27 增加 F-43 首页推荐轮次记录、接受率与反馈完成率。聊天与直接从行动池开始不属于 F-43 的分母。v0.28 实现 F-50，用户可选择朋友、温柔或轻暧昧风格，也可手写或导入设定。

### 2.3 关键技术

状态分为经验规则，不是医学评分。推荐采用 Thompson 采样：评分 ≥4 记成功，Beta(1+成功,1+失败)，零样本加 0.18 探索。评分与会话清除原子保存，选择事件和会话同时提交。网页使用同一采样方法；所有网页轮次标为演示。

### 2.4 其他相关技术

可选大模型只承担对话与行动建议，失败回退本地；用户自行配置服务。系统备份关闭，业务备份排除模型凭据。正式包采用持久发布签名，另提供旧 debug 签名兼容包。

## 3 项目计划

### 3.1 可行性分析

v0.28 的 JVM 和网页检查已有可复跑结果，原生验收范围以版本验证记录为准。v0.27 曾在手机上同签名覆盖升级并保留旧记录。v0.28 未连接真机、未调用真实 DeepSeek；实时 BLE、实际睡眠链路与长期提醒仍待验证。

### 3.2 风险与应对

| 风险 | 处理 |
|---|---|
| 无真实试用结论 | 先收集展示、选择和反馈，再开展 14 天试用 |
| BLE 被其他应用占用 | 使用心率广播、提示连接状态，保留无设备降级 |
| 睡眠记录缺失或片段化 | 缺失跳过；固定昨夜窗口合并重叠片段 |
| 签名不同导致无法覆盖 | 老用户用兼容包，正式包给新安装；不自动卸载 |
| 文档数字漂移 | CI 检查构建版本、六份文档、验证清单与 JVM 数量 |

### 3.3 里程碑与分工

本轮交付 F-50 陪伴设定，F-44–F-49 仍属 R1 规划，既有反馈来源缺口仍待解决。R1 用户研究尚未执行，后续安排 10 人访谈及 8–12 人连续试用 14 天。队长、队员、指导教师及官方提交期限需由团队核定；仓库旧计划不能代替赛事最新公告。

### 3.4 资源与预算

使用现有电脑、安卓手机、手环和开源工具；本轮未采购设备。大模型调用费用取决于用户配置，不承诺零成本。参与者招募与时间投入尚待团队落实。

## 4 预期成果与验证方式

交付源码、两种签名 APK、网页演示、证据包、六份当前文档和试用方案。主要观察指标：真实选择轮次/真实展示轮次；提交反馈的已选择轮次/已选择轮次；反馈 ≥4 比例及退出原因。窗口最多保留最近 5000 轮；旧版本不补造推荐历史。

## 5 总结与展望

当前可验证工程流程与推荐口径。下一阶段以真实试用验证“是否愿意采用、是否容易完成”，保持小样本结论的边界。
