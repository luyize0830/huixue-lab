# 用户设定文档

在 Android「我的 → 她的性格」点击「导入设定文档」，选择 TXT、Markdown 或 Word（.docx）。

1. 先查看文件名、提取正文和字符数；这一步不会改动草稿或已保存设定。
2. 点击「放入编辑框」后进入自定义档，可以继续修改或撤销本次导入。
3. 点击「保存」才会用于下一次模型对话；可以撤销上次保存或恢复默认。

[温柔陪伴](温柔陪伴.md)与[轻暧昧](轻暧昧.md)可直接下载导入。预设中的朋友小夜、温柔陪伴、轻暧昧同样可以直接选择；历史冷淡、吐槽风格保留。

## 支持范围

- 文件最大 512 KB，正文最多 6000 字符（应用按 UTF-16 字符单元计数）；不静默截断。
- TXT/MD 使用 UTF-8；DOCX 只提取正文文字、段落、换行与制表，不执行宏、不读取外链，不导入图片、批注和页眉页脚。
- 旧 .doc、PDF、图片、扫描件、加密文档和角色卡 JSON/PNG 暂不支持。可先另存为 UTF-8 文本或普通 DOCX。
- 本版设定作用于角色语气、称呼与相处方式；界面角色名称仍为小夜，聊天输出格式和行动约束仍由应用管理。
- 文件仅在本机读取，预览不调用模型；保存后的正文会随聊天发送给用户配置的模型服务。没有配置模型时仍走本地规则，人设不会驱动本地回复。
- 设定不是聊天记忆。导入不增加长期记忆能力，也不会清空聊天记录；当前模型上下文和记忆能力仍有原有长度限制。
- 业务备份包含当前设定；最近一次保存的撤销副本仅保留在本机，不随业务备份导出。
