
- [ ] 6 例全部执行，失败 / 跳过为 0

## 2. BLE 心率链路

- [ ] 扫描页能搜到手环并连接（记录耗时）
- [ ] 实时心率数值随呼吸 / 运动变化，不是恒定假值
- [ ] 断开手环后界面给出明确状态，不崩溃、不假装还在连
- [ ] 重新连接可恢复读数

## 3. 计时与通知

已知边界：当前没有常驻计时服务，进程被系统终止时**不保证**准点完成通知。本节就是来实测这个边界到底在哪。

- [ ] 计时中锁屏，到点有振动 / 通知
- [ ] 计时中切后台，到点有振动 / 通知
- [ ] 计时中手动杀进程，重新打开：进度按截止时间恢复；到点通知有 / 无（如实记录）
- [ ] 主动提醒（F-07）在 App 未打开时按时触发

## 4. 语音（TTS）

- [ ] 设置里打开语音，聊天回复正常朗读
- [ ] 离开聊天页立即停止朗读
- [ ] 关闭语音后不再朗读

## 5. 备份与恢复（原生文件流程）

JVM 与网页已验证编解码逻辑；这里只验原生文件选择与持久化。

- [ ] 导出：系统文件选择器保存 JSON 成功，文件可被再次选中
- [ ] 导入：预览条数正确 → 确认替换 → 数据一致
- [ ] 导入中途取消 / 选错文件：现有数据不被破坏
- [ ] 撤销导入可回到导入前状态
- [ ] 旋转屏幕时导入 / 计时状态不丢失

## 6. 真实模型链路

- [ ] 填入真实接口地址 / 模型 / Key 后，聊天能收到真实回复
- [ ] 故意填错 Key：提示 401 类原因，并能点「改设置」改回来
- [ ] 断网发送：提示超时 / 网络原因，不转圈假死
- [ ] 人设（性格）在多轮对话中保持，不跑偏回默认腔调

## 7. Health Connect 与使用统计

- [ ] 授权后能读到步数与睡眠（记录读到的最近日期）
- [ ] 拒绝授权时界面明确降级，不反复弹窗
- [ ] 使用统计（连续使用时长）在授予权限后数值合理
