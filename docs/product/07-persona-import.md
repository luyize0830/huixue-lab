# R2 增补：可选择、可导入的陪伴设定

> 2026-11-27。用户在 R1 后明确提出 DeepSeek 陪伴设定，并确认用户可自行导入设定文档。本次优先实现独立功能 F-50；它不表示 R1 的 F-44–F-49 已完成，也不证明陪伴已经成为经用户研究验证的主线。

## 产品决定

保留朋友小夜、温柔陪伴，增加主动选择的轻暧昧档；历史预设继续可用。内置设定不合适时，用户可以手写或导入自己的文档，无需修改代码。

采用「文件选择 → 正文预览 → 放入编辑框 → 保存」流程。取消预览不改草稿；确认导入可撤销；保存前返回会提示；恢复默认和撤销已保存设定需确认。只有保存成功才提示已生效，下一条模型请求读取最新设定。

## F-50 验收

- TXT、MD、DOCX 可读取；格式错误、空白、乱码、文件超过 512 KB、正文超过 6000 字符均明确拒绝，原设定不变。
- DOCX 正文按段落保留，禁止 DTD/外部实体，并限制正文和总解压量；不执行文档内容。
- 读取在 IO 线程进行；选择器返回取消、权限丢失或文件不可读都有退出路径。
- 导入预览与真正保存分开；切换预设、手写、导入、恢复默认、撤销均不删除聊天与行动数据。
- 原子保存 preset 与 custom，保存失败不能显示成功；最近一次保存可撤销，业务备份只携带当前设定。
- 当前设定会传给用户选择的模型服务；预览不联网，没有 Key 的本地规则不能假装已按设定生成。
- 完整和精简模型提示都携带用户设定；身份说明不会被聊天文本处理器误删。

## 与 R1 的关系

F-50 是用户最新要求驱动的独立交付，发布为 v0.28。R1 中 M1 的 v0.28 只是候选编号，后续可信数据闭环另行确定实际版本。F-44–F-49、三页主流程、真人访谈和两周试用继续保持待实现/待执行，不借本次人设功能提前宣称完成。

先检查用户是否能独立导入、预览、保存并辨认生效范围，再用真实模型对话测试风格一致性。当前工程测试不能替代 DeepSeek 实聊，角色记忆仍保留既有限制。
