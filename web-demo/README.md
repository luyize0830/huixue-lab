# 网页演示版（web-demo）

这份是给「手机装不了 APK」的场景准备的：一个单文件网页，任何能开浏览器的设备打开就能用，**不用安装、不用联网**（打开后所有逻辑都在本机跑）。

## 它是什么，不是什么

| | 网页版（这里） | 安卓版（仓库根目录） |
|---|---|---|
| 用途 | 让人 30 秒看懂产品闭环 | 真实采集与记录 |
| 数据 | 首页「演示数据」三条滑杆手动调 | 手环心率、系统使用统计、计步器久坐 |
| 记录 | 存在浏览器 localStorage | 存在 App 私有目录 |
| 角色 | 「小夜」是内联 SVG + 本地规则 | 小夜可接你自己的模型（OpenAI 兼容） |
| 规则 | `assess / moodOf / recsFor / parseIntent` 与安卓版同一套阈值 | 同左，且有 197 个单元测试钉住 |

一句话：**网页版是给人看的，安卓版是给数据用的，两边是同一套规则。**

## 怎么打开

- 直接双击 `index.html`（Chrome / Edge / Safari 都行）；
- 或者在本目录起一个静态服务：`python -m http.server 8765`，手机连同一个 WiFi 后打开 `http://<电脑IP>:8765/`。

## 自检

`selftest.js` 用 Node 打桩（document / window / localStorage / confirm）跑核心逻辑，21 条断言覆盖：深夜扣分、推荐过滤社交类、时间预算解析、场景识别、条数上限、三态头像、行动池 26 条且 id 唯一。

```bash
node selftest.js
```

## 已知限制

- 没有真实传感器数据，状态分靠滑杆演示；
- 不调用大模型（网页里没有 Key 这一层），回答走本地规则；
- 记录只在本浏览器里，换设备/清缓存就没了。
