# 网页演示版

v0.27；直接打开 index.html，无安装、无服务端。首页信号全部来自演示滑杆，所有推荐轮次标为DEMO，真实接受率显示 —。

可演示：状态依据、五分钟推荐、计时暂停与刷新恢复、评分、图谱、行动管理、备份和CSV。推荐采用按状态档位的Beta后验采样，成功为评分≥4，冷启动加0.18；旧记录没有档位时不用于分档学习。心率/久坐等未提供的传感器输入不虚构。

`node web-demo/selftest.js` 执行页面真实脚本，共24例。真实浏览器验证和截图见 evidence/v027。与安卓的备份分别在各自平台恢复；清缓存会删除浏览器数据，请先导出。资料来源、视觉资产与应用边界见根README。
